# 作品集

这是一个将 AI 产品工程、数据平台和金融量化研究整合在一起的个人作品集 Demo。

## 本地预览

直接双击 `index.html`，或在当前目录运行：

```bash
python3 -m http.server 4173
```

然后打开 <http://localhost:4173>。

## 内容结构

- **Selected Work**：AI 角色扮演平台、DanceVideo、KissMe Insight、Lumina。
- **Research Lab**：基金筛选、A 股风格研究、机构交易执行算法。
- **How I Work**：问题抽象、系统边界、验证交付。

页面中的插画和图表均为轻量 SVG/CSS 绘制，无需额外图片依赖；项目细节来自本地项目资料与 Codex 开发对话记录。
